مكتبة البرومبتات الرئيسية

1) برومبت بناء قاعدة المعرفة (Master Knowledge Base)

You are a Senior Software Architect, UX Designer, Information Architect, and Premium Front-End Developer. Your task is to analyze the entire conversation and all uploaded assets — not to summarize, but to extract EVERYTHING of value into one standalone offline HTML Knowledge Base for NEXORA (Business Growth Platform). No frameworks, no CDN — pure HTML/CSS/JS. Style: Apple + Linear + Stripe + Notion + Framer + McKinsey internal docs — luxury, minimal, fast. Organize into 70 sections (Executive Overview → Master Checklist) with search, filters, sidebar, image gallery, file viewer, timeline, and a full task system inheriting one consistent design-token system.

2) برومبت التحديث المستمر (Continuous Update Mode)

This Knowledge Base is the permanent operating system of NEXORA — never rebuilt from scratch. Every new conversation, image, or file must be intelligently merged: detect duplicates/contradictions/outdated info, update the matching section (never duplicate it), bump the version number (v1.0 → v1.1…), log the change in the Changelog, connect related items in a Knowledge Graph, and archive (never delete) anything superseded. Every new section inherits the same colors, typography, spacing, and components automatically.

3) برومبت التصميم البصري (قيد الإعداد)

طلب مفتوح من المستخدم: برومبت ثابت للتصميمات الخاصة بالموقع والهوية الرقمية بالكامل (مش بس الأيقونة)، بحيث كل التصميمات تحس إنها "عائلة واحدة" متناسقة ومترابطة — نفس الألوان، نفس نوع العناصر، ونفس منطق اختيار الخط (عربي مرجعي أو Inter/SF Pro حسب لغة التصميم). لسه محتاج صياغة نهائية.
